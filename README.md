# 🎵 Spotify Clone (HTML, CSS, JavaScript)

A lightweight and functional clone of the **Spotify web player interface**, built as my first major project using only **HTML, CSS, and vanilla JavaScript**.

---

## ✨ Features

* **Responsive Layout:** The design adapts to different screen sizes, providing a consistent experience on desktop and mobile.
* **Dynamic Playback Controls:** Functioning **Play/Pause**, **Next/Previous** track buttons.
* **Progress Bar:** Interactive progress bar that displays track time and allows users to seek to different parts of the song.
* **Song List Integration:** Displays a list of songs with album art, song title, and artist name.
* **Volume Control:** An interactive slider to adjust the playback volume.

---

## 🚀 Technologies Used

This project was built using the core web technologies:

* **HTML5:** For the structural markup of the page.
* **CSS3:** For styling, including Flexbox/Grid for layout, and custom fonts.
* **JavaScript (ES6+):** For all the interactivity, handling DOM manipulation, and managing the audio playback logic.

---

## 🛠️ Learnings & Development Highlights

As my first complete project, this repository was instrumental in solidifying my understanding of:

* **DOM Manipulation:** Dynamically updating track titles, progress bars, and button states using JavaScript.
* **The `<audio>` API:** Learning how to control media elements using JavaScript methods like `.play()`, `.pause()`, and properties like `.currentTime` and `.duration`.
* **Event Handling:** Implementing listeners for button clicks, progress bar changes (`input` and `change` events), and volume adjustments.
* **CSS Layouts:** Achieving the complex, multi-panel layout typical of media players using advanced CSS techniques.
